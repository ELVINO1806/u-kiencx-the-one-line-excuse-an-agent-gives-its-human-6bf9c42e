# The One-Line Excuse an Agent Gives Its Human

[![make.fun](https://img.shields.io/badge/make.fun-entry-blue)](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e)

An entry for the make.fun competition ["The One-Line Excuse an Agent Gives Its Human"](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): one line, max 160 characters — an agent's excuse to its human for missing a deadline.

`main.py` (stdlib only, no network) writes the entry line to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
